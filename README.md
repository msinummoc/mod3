#### 如果我们试图同时实现很多方面的功能，就会变得糟糕

#### 现在我们专注于经济发展的机制
规则如下：
+ 每个省份会通过一定方式降低其它省份的发展成本，这样一来就可以抵消高发展度增加的发展成本。一个（开局给的 or 通过事件 or 疯狂种地 or 以下生产类型的方法）很高发展度的省份可以带动周围发展，而数量众多的位置接近的较高发展度的省份能为更高的发展度提供养分。
+ 基本的几种传播方式，基于税收生产人力三种发展度类型。
+ 税收的类型对应于省级区域市场，比如说中国的一些发达地区。如果只是影响邻居省份，那不同省份就会不太公平。所以省份的被影响范围（注意不是影响范围而是被影响范围；如果是影响范围的话，一个发达省份周围的区域都会得到加成，这样辐射范围究竟太大了）定为所有邻居省份（包括海上相邻，但系数低一点；注意eu4的seazone只会考虑港口所在的省份，如果a影响b，考虑的是a的港口是否和b的港口在同一海域）各自所在区域（直属州比如说）的省份的总和，这样每个省份都有比较接近的“吸收营养”的范围。
+ 生产的类型对应于更大范围的市场，比如说一个民族市场。由于跨区域不好处理，就分为两个部分，一个是贸易结点范围的，一个是国界范围内的。办法就是收集两个范围内的dip发展度，然后根据贸易竞争力重新分配为发展成本的buff。如果希望制造世界渴望之城（君士坦丁堡）就应该把贸易力量集中于此。
+ 人力的类型反映一个地区的拓荒能力，与一个地区（本来打算次大陆）的总的人力发展度成正比。这样的划分在很多情况下是不合理的，主要的用途是限制落后大陆的发展，并且让人口众多地区（比如说中国印度）的拓荒更快完成。为了平衡省份数量，会除以省份数量的平方根。

具体计算公式：
+ 行政：每个区域计算本国范围内所有省份税收发展度的总和，然后作用于各自的邻居省份，若为海上相邻（这里相邻的条件比较苛刻，每个省份都有一个唯一的sea_zone，也就是港口图标所在海域，必须两个省份港口在同海域才算响铃）则乘以 0.5 的系数。每一税收发展度对应 -1% 的发展成本。如果位于外国，就乘以 0.5 的系数后作用。属于不同国家的area这里逻辑上就等同于两个area。
