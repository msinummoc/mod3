# mod3：区域发展与经济扩散

（ codex 写的，很多地方在胡扯，但暂时懒得改了

本模组重新设计了 EU4 的发展机制。

在原版中，发展度越高，继续发展通常越昂贵；在本模组中，一个繁荣省份也会带动周边地区、贸易市场和人口腹地。玩家不再只是寻找发展成本最低的单个省份，而是可以经营一整个相互促进的经济圈。

模组同时加入了省份自然发展与衰退：和平、低灾荒、低发展成本以及持续投入，会提高省份自然成长的机会；战争和灾荒则可能造成发展倒退。

## 核心逻辑：省份如何降低发展成本

每个城市省份都会从三种渠道获得发展成本减免：

- 税收发展代表周边的行政与区域市场；
- 生产发展代表贸易网络中的商业市场；
- 人力发展代表国家、地区和次大陆的人口基础。

三部分加在一起，每 `1` 点计算结果大致对应 `-1%` 本地发展成本。结果每年重新计算一次；手动发展省份时，与历史发展水平有关的惩罚会立即更新。

### 省份自身的贡献能力

发展度越高，一个省份向外提供的帮助越强，但并不是简单地按发展度线性增加。

| 省份总发展度 | 每点税收或生产发展采用的贡献系数 |
| --- | ---: |
| 0–9 | 0.30 |
| 10–19 | 0.70 |
| 20–29 | 1.10 |
| 30–39 | 1.50 |
| 40–49 | 1.75 |
| 50–59 | 2.00 |
| 60–69 | 2.25 |
| 70 以上 | 每增加 10 点发展度，系数再提高 0.20 |

因此，少数真正繁荣的核心城市能够明显带动周围；多个中高发展省份聚集在一起，也可以形成稳定的发展中心。

### 行政传播：由附近省份带动

税收发展主要在附近传播。

一个省份会吸收本国所属区域以及相邻区域的税收发展贡献。一个区域就是一个直属州的大小。陆地相邻传播最有效；跨国传播减半；通过同一海域连接的港口也可以互相影响，但效果进一步降低。

简单来说：

- 本国陆地范围按完整效果计算；
- 外国陆地邻接按一半效果计算；
- 本国海上邻接按一半效果计算；
- 外国海上邻接按四分之一效果计算。

行政传播还会根据参与省份数量进行平衡（会大致除以相邻省份数量的根号），避免省份特别密集的地区仅靠数量获得较大优势。建设连续、紧凑的高税收区域，比零散地发展孤立省份更有效。

### 外交传播：由贸易网络带动

生产发展通过贸易节点传播。

每个国家视为一个市场，市场包括所有该国有贸易竞争力的省份，会汇总节点内省份的生产发展(乘以对应的贸易份额的比例)，再根据各省份的贸易竞争力（正比）和发展度（三次方正比）重新分配，权重也会乘以贸易份额。本国省份在本国市场对应的计算中还会获得额外的 `25%` 权重。也就是说把各个贸易节点分割为了多国的市场的总和，叠加得到最终结果。

这样的结果就是，一个大的、贸易竞争力高的城市的所有者如果控制了较大范围的贸易，就可以获得更多贸易界面，形成跨区域的“价值”转移。

贸易公司省份的原始贸易力量在这项计算中只按四分之一计入。

对玩家而言，这意味着：

- 集中贸易力量不仅增加贸易收入，也会把生产发展带来的减免集中到重要节点；
- 市场、贸易仓库和证券交易所能够提高贸易力量，并直接增加生产发展；
- 控制一个富裕贸易节点，可以让节点中的核心商业省份更容易继续发展。

### 军事传播：由人口腹地带动

人力发展从三个范围提供帮助，都是取自该范围再作用于该范围：

- 国家：取本国省份的平均人力发展，再乘 `1.5`；
- 地区：汇总整个 `region` 的人力发展，并按省份数量的平方根折减，再乘 `0.3`；
- 次大陆：以同样方式汇总整个 `superregion`，再乘 `0.075`。

国家部分体现本国的人口与组织能力，地区和次大陆部分体现更大范围的人口基础。人口稠密的中国、印度和欧洲会更容易形成持续发展的区域，而省份很多但人力发展很低的地区不会仅靠省份数量获得过高收益。注意人力不会乘以之前说的贡献系数。

### 发展过快的惩罚

每个省份都会记录一个缓慢追赶现实发展度的“历史发展水平”。如果玩家在短时间内连续种地，使实际发展度明显超过这一水平，每超出 `1` 点就会产生约 `+5%` 的发展成本。

这个惩罚会被行政、外交和军事传播提供的减免抵消。成熟的经济圈更能承受集中投资；缺少周边支撑的孤立省份则很难长期低成本种地。

最终结果会取整为整数百分比，并显示在省份修正 `development cost from other provinces` 中。提示信息还会列出行政、外交、军事、历史水平、发展惯性和自然增长概率等数据。

## 省份自然发展与衰退

每年结算传播效果后，每个城市省份会进行一次自然变化判定。

更容易自然发展的情况：

- 本地发展成本较低；
- 周边、贸易和人口传播提供了较强减免；
- 省份近期曾被手动发展或自然发展，积累了发展惯性；
- 实际发展落后于该省的历史发展水平；
- 省份没有灾荒。

更容易衰退的情况：

- 本地发展成本很高；
- 省份发展度较高但缺少经济圈支撑；
- 发展惯性较低；
- 存在灾荒。灾荒会大幅提高衰退机会，并把自然增长机会降为四分之一。

自然增长成功时，税收、生产或人力随机增加 `1`。当前已经最高的类别权重减半，因此三类发展通常会逐渐趋于均衡；省份还会获得 `5` 点下一思潮接纳进度。

自然衰退成功时，会从当前最高且至少为 `2` 的发展类别中随机减少 `1`，同时移除 `10` 灾荒度。同一年若已经发生衰退，就不会再自然增长。

手动发展一次会增加 `0.25` 发展惯性，自然增长会增加 `0.75`，惯性上限为 `5`。惯性每年衰减，并会受到灾荒额外削弱。

另外 ai 在自然增长的结算时会获得一些发展成本减免，还有全球的全局发展成本的随机波动，以及时代的波动。具体来说就是发展速度大革命时代 > 教改 > 地理大发现 > 专制。

## 发展成本的基础环境

为了让区域传播成为主要的减费来源，模组提高了孤立省份和高发展省份的基础成本，再由经济圈提供的减免进行抵消。

相对原版，`static_modifiers` 中与发展成本直接相关的变化如下：

| 项目 | 原版 | mod3 |
| --- | ---: | ---: |
| 全国基础乘算发展成本 | 无 | `+50%` |
| 全国基础加算发展成本 | 无 | `+100%` |
| 所有城市的本地发展成本 | 无 | `+75%` |
| 随总发展度增长的成本 | 每级 `+3%` | 每级 `+5%` |
| 每点税收发展附加成本 | 无 | `+3%` |
| 每点生产发展附加成本 | 无 | `+3%` |
| 每点人力发展附加成本 | 无 | `+3%` |
| 荒废度的发展成本影响 | `+20%` | `+100%` |
| 随国家体量缩放的乘算减免 | 无 | `-50%` |

极难 AI 原版的 `-20%` 直接发展成本被移除，改为 `-10%` 全点数花费；困难 AI 获得 `-5%` 全点数花费。

加算+100%部分是为了和减少的buff抵消，部分是为了避免出现叠高buff时低发展度省份发展成本显著更低的情况。


## 计算时间

- 开局时初始化所有贸易节点、地区、国家和省份数据；
- 每年重新计算一次行政、外交和军事传播；
- 年度脉冲约 3 天后应用发展成本修正，并进行自然发展或衰退判定；
- 每次手动增加税收、生产或人力时，立即增加发展惯性并更新该省的过度发展惩罚；
- 时代发展成本环境每年有 `10%` 概率改变，其余年份沿用原结果。

时代环境的倾向为：宗教改革时代总体更利于发展，专制时代总体更昂贵，革命时代再次变得较便宜；具体结果仍带有随机波动。

## 其他主要变化

### 发展、科技与顾问

- 手动发展基础成本：`50 → 40`；
- 君主点储存上限：`999 → 1999`；
- 科技基础成本：`600 → 800`；
- 科技年代成本系数：`0.30 → 0.85`；
- 每年超前科技惩罚：`10% → 5%`；
- 邻国科技减免：每级 `5% → 10%`，上限仍为 `75%`；
- 顾问最高等级：`5 → 10`；
- 顾问成本系数：`1.00 → 0.75`；
- 国家发展度缩放尺度：`600 → 1000`。

### AI

- AI 发展省份的基础上限由 `10` 提至 `20`，原始发展倍率上限由 `2` 提至 `3`；
- AI 基本忽略超出治理容量对其常规经济决策的限制，但治理容量已满时不能主动宣战；
- AI 宣战会额外考虑距离、文化、宗教、永久宣称和特定宣战理由；
- 所有统治者性格都更倾向避免丑陋、破碎的边界。

### 战争与外交

- 同文化组核心消失时间：`150 → 800` 年；
- 距离对侵略扩张的衰减参数：`0.75 → 0.85`；
- 索取省份的侵略扩张系数：`0.60 → 0.80`；
- 和约侵略扩张上限：`50 → 500`；
- 传播革命可获得的单项点数上限：`999 → 9999`。

### 经济与建筑

- 市场、贸易仓库、证券交易所分别提供 `1/2/3` 点生产发展；升级建筑时只增加等级差额，拆除时移除对应发展；
- 每点发展额外提供 `+0.3` 省份贸易力量、`+1%` 省份贸易力量、`+1%` 商品产出与 `+1%` 本地税收；
- 基础治理容量在脚本内部以 `2000 - 1800` 实现，实际基础值仍为 `200`；让大明开局能够全直辖。
- 基础税收、陆军与海军上限、知识共享速度、幸运国和难度加成等经过重新平衡。

### 中国与世界规则

- 明王朝危机要到宗教改革时代结束后才能启动；
- 天命的正面与负面效果经过调整；
- 韩国、部分草原政权、东印度和印度国家在 1445 年以前开局时有额外的发展度修改，印度略微增加，其余降低；
- 非首都的原住民省份被非原住民国家攻陷时会去殖民化；
- 八个原版思潮的出现与传播条件被完整重写；
- 东亚部分省份历史、明朝开局和地图地形分布有所调整。

### 思潮（重要）

把所有思潮的传播难度都提高了，并且严格限制出现条件，尤其是是后几个思潮，配合科技花费提高，有效限制后期 ai 疯狂种地。

## 提示

这个模组鼓励建设成片的核心区域，而不是把所有君主点投入一个孤立省份。想培养大型城市时，优先改善周边税收、控制所属贸易节点、提高关键省份贸易力量，并尽量避免灾荒。一个受到完整区域经济支撑的城市，才最容易长期保持低成本和自然增长。
